# Prompts – Framework IA / MCP

Ici tu stockes tes prompts standard que tu réutilises sur chaque projet.

Exemples de fichiers :

- `00-meta.md` : configuration générale de l’IA (rôle, style, priorités).
- `01-vision.md` : prompt pour clarifier la vision.
- `02-stories.md` : prompt pour user stories + evil stories.
- `03-specs_archi.md` : prompt pour specs + architecture + diagrammes.
- `04-plan_impl.md` : prompt pour roadmap + backlog.
- `05-dev_assistant.md` : prompt pour coder une feature.
- `06-code_review.md` : prompt pour revue clean code.
- `07-tests_security.md` : prompt pour renforcer tests + sécurité.

Tu peux coller ici les prompts qu’on a définis ensemble et les adapter.
