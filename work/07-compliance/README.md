# 07 – Compliance & Résilience

Ce dossier couvre les aspects **conformité, gouvernance des données et continuité d’activité**.

## Fichiers recommandés

- `data_governance.md` : comment les données sont gérées, classées, protégées.
- `legal_aspects.md` : contraintes légales, contrats, conformité (ex : RGPD, etc.).
- `disaster_recovery.md` : plan de reprise après sinistre, sauvegardes, RPO/RTO.

Ces fichiers font le lien avec la qualité (05) et l’architecture (03) en imposant des contraintes fortes de sécurité, de stockage et de résilience.
